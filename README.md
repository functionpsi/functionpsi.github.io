A static portfolio for **Rendani Manugeni**, publishing as **Function Psi**.

**Live:** `https://functionpsi.env.pm`  
**Source:** `github.com/functionpsi/functionpsi.github.io` (the `functionpsi` handle redirects here)

Thirteen pages. One Three.js hero that responds to pointer and scroll. A Projects page that pulls live repository data from GitHub, with a fallback snapshot when the API is rate-limited. Six numbered case studies — self-initiated concepts across 3D, Web3D, and Web — each with its own complete study. An About page built as a studio dossier with a sticky table of contents that actually tracks scroll. A Contact page that composes a brief in the browser and copies it to your clipboard, then opens X. No server, no form endpoint, no email address. Cookie consent that remembers your choice and an optional “recently viewed” memory. Privacy policy v1.1 that discloses the GitHub API call and the session cache. Terms of use. A 404 page with a pulse.

Built with Three.js 0.170, GSAP 3.13, Lenis 1.3.11. Type: Instrument Serif, Bricolage Grotesque, DM Mono. Colours: lime, iris, ember, cyan on near-black. No build step. No analytics. No tracking. The HTML is committed; GitHub Pages serves it directly.
